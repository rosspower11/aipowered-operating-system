# Job Description Writer

A skill for writing a job description that does real work — pulls in the right candidates, deflects the wrong ones, and tells the hiring manager what the role is actually for. Most JDs read like a wishlist of skills; this one reads like a contract: here's the outcome, here's the work, here's what you'll trade.

## When to use this skill

- Opening a new role and the hiring manager has only a title in mind
- Re-writing a stale JD that's been recycled across three different jobs
- A role that's been open for 60+ days with weak candidates — the JD is usually the leak
- When the team disagrees on what the role is for

## When NOT to use this skill

- For an internal transfer or promotion — different artifact (role expectations doc)
- For a contractor SOW — that's a statement of work, not a JD

## How to run

### Step 1 — Inputs

Pull from the hiring manager:

1. **The outcome** — what's true 12 months in if this hire works? One sentence.
2. **First 90 days** — three concrete deliverables.
3. **Who they work with** — their manager, their peers, who they hand work to.
4. **Trade-offs** — what this role is *not*. ("This is an IC role, not a manager." "Heavy ops, light strategy.")
5. **Comp band + location** — actual range. Vague comp filters out the people you want.

If any of these are missing, push back before drafting. A JD without an outcome is a wishlist.

### Step 2 — Draft the JD

Use this structure:

```
# {Title}, {Team} — {Location, remote policy}

## What you'll own
{One paragraph. The outcome, in plain English.}

## In your first 90 days
- {Deliverable 1}
- {Deliverable 2}
- {Deliverable 3}

## A typical week
{4–6 bullets of actual tasks. Not "drive alignment." Real verbs: review, ship, interview, write.}

## You'll be a fit if
- {Concrete experience marker — not "10+ years"}
- {Skill that's actually load-bearing}
- {Mindset trait, anchored to a behavior}

## You probably won't enjoy this if
- {Honest anti-fit, e.g., "you want a fully built playbook"}
- {Another anti-fit}

## Comp + benefits
{Real range. Equity if relevant. Don't hide it.}
```

### Step 3 — Voice rules

- Second person ("you'll own"), not third ("the candidate will").
- No HR-speak: cut "synergy", "drive alignment", "thought leader", "rockstar", "ninja".
- No skills lists with 14 bullets. If everything is required, nothing is.
- Specific over senior — "shipped 2 0→1 products" beats "10+ years experience."
- Anti-fit section is non-negotiable. It's the strongest filter you have.

### Step 4 — Quality check

- Could a strong candidate from a competitor read this and know if they'd be good at it? If not, rewrite.
- Does the JD repel at least one type of person? If not, you've written marketing copy.
- Is the outcome statement still true if you change the title? If yes, the title is wrong.

## Hand-off

End with a one-line summary the hiring manager can paste into their LinkedIn post or referral DM: `Hiring a {title} to {outcome}. {Location}. {Comp range}. JD: {link}.` Offer to draft a referral-ask message and a "not a fit" rejection template in the same voice.
