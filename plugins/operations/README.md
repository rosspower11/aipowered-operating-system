# Operations

Plug-ins for the unsung work that keeps a company moving — meetings, comms, planning, and hiring.

## When to install

You're running ops, chief of staff, or you're the founder who somehow inherited all of this, and you want to:

- Turn meeting recordings into decisions and owners, not transcripts
- Write weekly updates that people actually read end-to-end
- Run quarterly planning without it eating two full weeks
- Move hiring from chaos to a tight, repeatable loop

## Categories

| Category | What lives here |
|---|---|
| `meetings` | Notes, summaries, action items, agendas |
| `comms` | Weekly updates, all-hands, board updates, internal memos |
| `planning` | OKRs, quarterly planning, retros, post-mortems |
| `hiring` | Job descriptions, interview kits, scorecards, offer letters |
