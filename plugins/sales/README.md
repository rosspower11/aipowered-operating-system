# Sales

Plug-ins to run outbound, manage pipeline, and close more deals — without losing your voice.

## When to install

You're running a sales motion (founder-led or rep-led) and want to:

- Send cold emails that don't read like cold emails
- Move deals through stages with shared context, not vibes
- Run discovery calls that surface the real budget, timeline, and decision-maker
- Handle objections with a real answer, not a deflection

## Categories

| Category | What lives here |
|---|---|
| `outbound` | Cold email, LinkedIn, sequencing, list building |
| `pipeline` | Stage hygiene, forecasting, deal review |
| `discovery` | Qualification frameworks, call prep, follow-ups |
| `closing` | Negotiation, contract review, objection handling |

## Skills

### Free

- [Cold Email Architect](./skills/aipowered-cold-email-architect/SKILL.md) — `aipowered-cold-email-architect` — *free* — A skill that writes cold emails using proven frameworks, generates A/B variants, and structures multi-step sequences with branching logic.
- [ICP Builder](./skills/aipowered-icp-builder/SKILL.md) — `aipowered-icp-builder` — *free* — Turns a fuzzy "B2B SaaS" target into a specific, testable ICP with named accounts and provable triggers — the kind a rep can prospect against on Monday morning.
- [Discovery Call Prepper](./skills/aipowered-discovery-call-prepper/SKILL.md) — `aipowered-discovery-call-prepper` — *free* — Researches a named account, then drafts a 30-minute discovery call plan with the right questions in the right order — so the rep walks in informed, not improvising.

### Pro

- [LinkedIn Prospector](./skills/aipowered-linkedin-prospector/SKILL.md) — `aipowered-linkedin-prospector` — *pro* — Designs a connection note plus a 4-touch DM cadence by ICP, with reply-trigger logic and language that survives the recruiter filter — without sounding like every other AE on the platform.
- [Pipeline Reviewer](./skills/aipowered-pipeline-reviewer/SKILL.md) — `aipowered-pipeline-reviewer` — *pro* — Walks a deal-by-deal pipeline pass — surfaces stalled deals, missing next steps, and at-risk forecast commits, then prescribes the move that gets each one unstuck.
- [Deal Forecaster](./skills/aipowered-deal-forecaster/SKILL.md) — `aipowered-deal-forecaster` — *pro* — Builds a quarterly forecast with confidence bands by deal — best case, commit, worst case — defendable in a board meeting and grounded in MEDDPICC evidence, not gut feel.
- [MEDDPICC Qualifier](./skills/aipowered-meddpicc-qualifier/SKILL.md) — `aipowered-meddpicc-qualifier` — *pro* — Scores a live deal against MEDDPICC, names which letters are weak, and prescribes the next move to fill the gap — turns the framework from a checklist into a working tool.
- [Closing Call Runner](./skills/aipowered-closing-call-runner/SKILL.md) — `aipowered-closing-call-runner` — *pro* — Structures a 30-minute closing call — recap, price reveal, objection plan, and signature push — so the rep walks in with a script for the moment the buyer says "what's the number?"
- [Negotiation Coach](./skills/aipowered-negotiation-coach/SKILL.md) — `aipowered-negotiation-coach` — *pro* — Reads a buyer's counter, returns three responses scored by leverage and risk, and the line you should never cross — so the rep doesn't give away the deal in a Slack to legal at 9pm.
- [Proposal Writer](./skills/aipowered-proposal-writer/SKILL.md) — `aipowered-proposal-writer` — *pro* — Turns discovery notes into a tight 2-page proposal with scope, price, and named outcomes — no boilerplate, no executive summary written for an executive who won't read it.
